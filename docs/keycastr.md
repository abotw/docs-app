# KeyCastr

## 1. What Is KeyCastr?

**KeyCastr** is a small utility for **macOS** that **displays your keystrokes on screen in real time**.

It is commonly used for:

-   Screen recording
-   Live teaching or presentations
-   Programming tutorials
-   Demo videos

When you press keys like `⌘ + C`, the shortcut appears on the screen so viewers can easily follow.

------

## 2. Do You Need KeyCastr?

You should use KeyCastr if:

-   You are on **macOS**
-   You record screen tutorials
-   You teach or explain software usage
-   You want viewers to see keyboard shortcuts clearly

If you don’t record or present your screen, you probably don’t need it.

------

## 3. Download and Install KeyCastr

1.  Visit the official site or GitHub page:
    -   https://github.com/keycastr/keycastr
2.  Download the latest **KeyCastr.dmg**
3.  Drag **KeyCastr** into **Applications**
4.  Launch **KeyCastr**

The app runs in the **menu bar**.

------

## 4. First Launch: Grant Permissions (Very Important)

macOS will ask for permission:

### Enable Input Monitoring

1.  Open **System Settings**
2.  Go to **Privacy & Security**
3.  Select **Input Monitoring**
4.  Enable **KeyCastr**
5.  Restart KeyCastr if required

Without this permission, KeyCastr cannot show keystrokes.

------

## 5. Understanding How KeyCastr Works

Once running:

-   KeyCastr listens to your keyboard input
-   Displays pressed keys on screen
-   Works in all apps (Terminal, Browser, IDE, etc.)

It does **not** record:

-   Typed text content (only key presses)
-   Password fields (usually hidden)

------

## 6. Basic Usage (Very Simple)

1.  Make sure KeyCastr is running (menu bar icon visible)
2.  Press some keys:
    -   `⌘ + C`
    -   `⌘ + V`
    -   `⌘ + Shift + 4`
3.  The keys appear on screen automatically

No extra steps needed.

------

## 7. Customize Display Style

Click the **KeyCastr icon** in the menu bar.

### Common Settings

-   **Display Mode**
    -   Floating
    -   Mouse location
-   **Font Size**
    -   Increase for recordings
-   **Color / Theme**
    -   Light or dark
-   **Fade-out Time**
    -   How long keys stay visible

Recommended for recordings:

-   Larger font
-   Slight delay before fading

------

## 8. Show Only Shortcuts (Recommended)

To avoid clutter:

-   Enable **Show Modifier Keys**
-   Disable continuous single-character display

This keeps output clean:

```text
⌘ + C
⌘ + V
⌘ + Z
```

------

## 9. Using KeyCastr with Screen Recording

KeyCastr works well with:

-   QuickTime Player
-   OBS Studio
-   ScreenFlow

### Typical Workflow

1.  Start KeyCastr
2.  Start screen recording
3.  Perform demo
4.  Stop recording

The keystrokes are recorded as part of the video.

------

## 10. Temporarily Hide Keystrokes

Before typing sensitive data:

-   Click KeyCastr menu
-   Choose **Pause**
-   Type password
-   Resume afterward

Very important for security.

------

## 11. Common Beginner Problems

### ❌ No Keys Displayed

-   Input Monitoring not enabled
-   App needs restart

### ❌ Too Many Keys on Screen

-   Disable single key display
-   Show only shortcuts

### ❌ Keys Cover Important UI

-   Change display position
-   Move to mouse-follow mode

------

## 12. Best Practices

-   Pause KeyCastr when typing passwords
-   Use large font size for tutorials
-   Test before recording
-   Combine with clear narration
