# Alfred-01

## 1. What Is Alfred?

**Alfred** is a macOS productivity app that lets you control your Mac **using the keyboard instead of the mouse**.

With Alfred, you can:

-   Launch apps instantly
-   Search files and folders
-   Perform calculations and conversions
-   Control system functions
-   Automate tasks with workflows

In short: **Alfred replaces and greatly extends Spotlight**.

------

## 2. Installing Alfred

1.  Go to the official website:
    👉 [https://www.alfredapp.com](https://www.alfredapp.com/)
2.  Download **Alfred for Mac**
3.  Drag Alfred into the **Applications** folder
4.  Launch Alfred

Alfred will ask for permissions (Accessibility, Automation).
👉 **Allow them**, or some features won’t work.

------

## 3. Opening Alfred

The default shortcut is:

```
⌘ + Space
```

If this conflicts with Spotlight:

-   Open **Alfred Preferences**
-   Go to **General**
-   Change the **Hotkey** (many people use `Option + Space`)

------

## 4. Basic Usage (Must-Know)

### 4.1 Launch Apps

1.  Press `⌘ + Space`

2.  Type an app name:

    ```
    safari
    vscode
    terminal
    ```

3.  Press `Enter`

✔ Much faster than Dock or Launchpad

------

### 4.2 Search Files & Folders

Just type the file name:

```
report
notes
todo
```

Alfred searches:

-   Files
-   Folders
-   Recently used documents

Tip:

-   Press `⌘ + Enter` → reveal in Finder
-   Press `Option + Enter` → show file actions

------

### 4.3 File Actions (Very Powerful)

1.  Search for a file
2.  Press `→` (right arrow)

Now you can:

-   Open
-   Move
-   Copy
-   Email
-   Show in Finder
-   Delete

------

## 5. Built-in Tools You Should Use

### 5.1 Calculator

Type:

```
123 * 45
(100 + 20) / 4
```

Press `Enter` → result is copied to clipboard automatically.

------

### 5.2 Unit & Currency Conversion

Examples:

```
10 km to mile
5 gb to mb
100 usd to cny
```

(Internet required for currency rates)

------

### 5.3 Dictionary & Spelling

```
define efficiency
spell recommend
```

Great for quick English checks.

------

## 6. Web Search with Keywords

Alfred supports **keyword-based web searches**.

Examples:

```
google ssh tutorial
wiki Linux
github alfred workflow
```

You can customize these in:

```
Preferences → Features → Web Search
```

------

## 7. Clipboard History (Powerful Feature)

⚠️ Requires **Alfred Powerpack** (paid, one-time license).

### Enable Clipboard History:

```
Preferences → Features → Clipboard History → Enable
```

### Use it:

-   Shortcut: `⌘ + Shift + C`
-   Browse everything you copied before
-   Paste old text, links, or code snippets

Perfect for coding and writing.

------

## 8. Snippets (Text Expansion)

Also requires **Powerpack**.

Example:

-   Type: `;addr`
-   Alfred expands it to your full address

### Set up:

```
Preferences → Features → Snippets
```

Great for:

-   Email templates
-   Code snippets
-   Common replies

------

## 9. Workflows (Automation Core)

Workflows let you **automate complex tasks**.

Examples:

-   One keyword to open several apps
-   Search StackOverflow from Alfred
-   Run shell / Python scripts
-   Control Homebrew, Git, SSH, Docker

### Browse workflows:

👉 https://alfred.app/workflows/

Even beginners can use workflows without writing code.

------

## 10. Alfred vs Spotlight (Quick Comparison)

| Feature           | Spotlight | Alfred     |
| ----------------- | --------- | ---------- |
| App launching     | ✅         | ✅ (faster) |
| File actions      | ❌         | ✅          |
| Clipboard history | ❌         | ✅          |
| Workflows         | ❌         | ✅          |
| Custom searches   | ❌         | ✅          |

👉 Many users **disable Spotlight after using Alfred**.

------

## 11. Recommended Beginner Settings

In **Preferences**:

-   **General**
    -   Set a comfortable hotkey
-   **Features → Default Results**
    -   Enable Apps, Files, Folders
-   **Advanced**
    -   Enable “Fuzzy Matching” (optional)
