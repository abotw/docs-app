**Extension for Bilibili Player** is a Chrome extension that enhances the Bilibili web video player by adding **powerful keyboard shortcuts**, **better default behaviors**, and **extra viewing features**.
It is especially useful if you prefer keyboard control or watch long videos regularly.

Chrome Web Store:
https://chromewebstore.google.com/detail/extension-for-bilibili-pl/ffoljpljalicgkljioegejmigkkkincm

## 1️⃣ What Does This Extension Do?

After installation, the extension **automatically works on Bilibili video pages** and provides:

-   More consistent and powerful keyboard shortcuts
-   Better control over fullscreen, wide mode, and web fullscreen
-   Quick toggle for danmaku (bullet comments)
-   Playback speed control
-   Screenshot and Picture-in-Picture support
-   Cleaner viewing experience with optional UI hiding

No login or complex setup required.

## 2️⃣ Installation

1.  Open **Chrome** (or Chromium-based browsers like Edge / Brave).
2.  Open the extension page in Chrome Web Store.
3.  Click **Add to Chrome** → **Add extension**.
4.  (Optional) Pin the extension from the browser toolbar for quick access.

Once installed, it works automatically on `bilibili.com`.

## 3️⃣ Default Behavior (Out of the Box)

By default, the extension:

-   Enables all enhanced keyboard shortcuts
-   Forces **Space** to play/pause video (instead of scrolling the page)
-   Automatically applies preferred display modes
-   Allows quick danmaku on/off switching
-   Improves fullscreen and web fullscreen behavior

You can change all of these in the extension settings.

## 4️⃣ Default Keyboard Shortcuts

Below are the **most important shortcuts** you’ll use daily.

### ▶ Playback Control

| Action                    | Shortcut           |
| ------------------------- | ------------------ |
| Play / Pause              | **Space** or **K** |
| Seek backward (short)     | **J**              |
| Seek forward (short)      | **L**              |
| Seek backward (long)      | **Shift + J**      |
| Seek forward (long)       | **Shift + L**      |
| Next episode / next video | **N**              |
| Mute / Unmute             | **M**              |
| Speed up                  | **+**              |
| Slow down                 | **-**              |
| Reset speed               | **0**              |

### 📺 Screen & Display

| Action                    | Shortcut      |
| ------------------------- | ------------- |
| Fullscreen toggle         | **F**         |
| Web fullscreen            | **W**         |
| Wide screen mode          | **T**         |
| Toggle danmaku            | **D**         |
| Show danmaku status       | **Shift + D** |
| Lights on / off           | **I**         |
| Show / hide title         | **B**         |
| Show / hide progress time | **G**         |
| Show / hide current time  | **H**         |
| Toggle subtitles          | **C**         |

### 🧰 Advanced Features

| Action                   | Shortcut            |
| ------------------------ | ------------------- |
| Picture-in-Picture (PiP) | **P**               |

## 5️⃣ Extension Settings (Customization)

To open settings:

1.  Click the **extension icon** in the browser toolbar
2.  Select **Options / Settings**

You can:

-   Enable or disable specific shortcuts
-   Change seek time (short / long jumps)
-   Adjust playback speed step size
-   Disable features you don’t use
-   Avoid conflicts with browser or system shortcuts

⚠️ Refresh the Bilibili page after changing settings.

## 6️⃣ Tips for Beginners

-   **Start with Space, J, L, F, D** — these cover 90% of use cases
-   Disable shortcuts you never use to avoid conflicts
-   Use **PiP mode (P)** when multitasking
-   Turn off danmaku by default if you watch lectures or tutorials
-   Frame-by-frame mode is great for animation or technical videos

## 7️⃣ What This Extension Does *Not* Do

-   It does **not** download videos
-   It does **not** bypass Bilibili restrictions
-   It does **not** require a Bilibili account
-   It only enhances the **web player experience**

## 8️⃣ Who Is This Extension For?

✔ Heavy Bilibili users

✔ Keyboard-driven users

✔ Learners watching long courses

✔ Users who want YouTube-like controls on Bilibili
