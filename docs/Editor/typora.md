# Typora

## 1. What Is Typora?

**Typora** is a **Markdown editor** that provides a *What You See Is What You Mean* (WYSIWYM) experience.

Unlike traditional Markdown editors that split the screen into *source* and *preview*, Typora shows **formatted content directly while you type**, making writing smooth and distraction-free.

Typora is ideal for:

-   Notes
-   Documentation
-   Study materials
-   Technical writing
-   Blogs and README files

------

## 2. Why Use Typora?

### Key Advantages

-   ✅ Real-time Markdown rendering
-   ✅ Extremely clean interface
-   ✅ Cross-platform (macOS, Windows, Linux)
-   ✅ Export to PDF, HTML, Word, etc.
-   ✅ Excellent for long-form writing

### Who Typora Is For

-   Beginners learning Markdown
-   Students taking notes
-   Developers writing documentation
-   Anyone who wants clean, structured text

## 4. First Launch Overview

When you open Typora, you’ll see:

-   A blank writing area
-   No visible Markdown symbols (by default)
-   Minimal UI (menus appear when needed)

Typora focuses on **writing first, formatting second**.

------

## 5. What Is Markdown? (Quick Intro)

Markdown is a **plain-text formatting language**.

Instead of clicking buttons, you use simple symbols:

```markdown
# Heading 1
## Heading 2

**Bold**
*Italic*

- List item
- List item

[Link](https://example.com)
```

Typora automatically converts this into formatted text.

------

## 6. Basic Markdown You Should Know

### Headings

```markdown
# Title
## Section
### Subsection
```

### Bold & Italic

```markdown
**bold**
*italic*
```

### Lists

```markdown
- Item
- Item

1. First
2. Second
```

### Links & Images

```markdown
[OpenAI](https://openai.com)
![Image](image.png)
```

## 7. Typora’s Live Preview (Core Feature)

In Typora:

-   You type Markdown
-   It **instantly becomes formatted text**
-   No preview pane needed

To see raw Markdown:

-   Menu: **View → Source Code Mode**

------

### Inline Code

### Code Blocks

- Detects the language
- Applies syntax highlighting

## 9. Tables (Very Easy in Typora)

Type this:
```markdown
| Name | Score |
|------|-------|
| Alice | 90 |
| Bob | 85 |
```

Typora converts it into a formatted table instantly.

You can also:

-   Right-click to add rows/columns
-   Edit tables visually

## 11. File Management

### Open Files / Folders

-   `Cmd + O` – Open file
-   **File → Open Folder** – Work like a notebook

### Recommended Structure

```
notes/
├── os.md
├── networks.md
├── images/
```

Typora handles relative paths very well.

## 15. Typora vs Other Editors

| Tool      | Best Use                    |
