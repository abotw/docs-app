# CotEditor

## 1. What Is CotEditor?

**CotEditor** is a **lightweight, fast, and native macOS text editor**.
It is especially popular among developers and power users who want:

-   A clean, distraction-free interface
-   Excellent support for plain text and source code
-   Native macOS performance (no Electron, no Java)
-   Powerful text manipulation tools

Think of CotEditor as a **more powerful alternative to TextEdit**, but simpler and faster than heavy IDEs.

------

## 2. Why Use CotEditor?

### Key Advantages

-   ✅ **Native macOS app** (very fast, low memory usage)
-   ✅ **Syntax highlighting** for many languages
-   ✅ **Powerful find & replace**
-   ✅ **Regular expression support**
-   ✅ **Encoding and line-ending control**
-   ✅ **Free and open source**

### Typical Use Cases

-   Editing configuration files
-   Writing scripts (Shell, Python, etc.)
-   Viewing and modifying logs
-   Writing Markdown or notes
-   Quick code edits without opening a full IDE

------

## 3. Installing CotEditor

### Method 1: Mac App Store (Recommended)

1.  Open **App Store**
2.  Search for **CotEditor**
3.  Click **Get → Install**

### Method 2: Official Website

-   Visit: [https://coteditor.com](https://coteditor.com/)
-   Download the latest `.dmg`
-   Drag CotEditor into **Applications**

------

## 4. First Launch Overview

When you open CotEditor, you’ll see:

-   **Menu Bar** – All features are here
-   **Editor Area** – Where you type and edit text
-   **Status Bar (bottom)** – Shows:
    -   Line / column number
    -   Encoding (UTF-8, etc.)
    -   Line endings (LF / CRLF)
    -   File type (syntax)

>   CotEditor focuses on **clarity and precision**, not visual clutter.

------

## 5. Opening and Saving Files

### Open a File

-   `Cmd + O`
-   Or drag a file directly into CotEditor

### Save a File

-   `Cmd + S`
-   “Save As”: `Cmd + Shift + S`

CotEditor can open **very large files** smoothly.

------

## 6. Understanding File Encoding

Encoding matters when working with text files.

### Common Encodings

-   **UTF-8** (recommended, default)
-   UTF-16
-   GB18030
-   ISO-8859-1

### Change Encoding

-   Menu: **View → Text Encoding**
-   Or click encoding in the **status bar**

>   If you see garbled characters, try changing encoding.

------

## 7. Line Endings Explained

Different systems use different line endings:

-   **LF** – macOS / Linux
-   **CRLF** – Windows
-   **CR** – old macOS (rare)

### Change Line Endings

-   Click **LF / CRLF** in the status bar
-   Or: **View → Line Endings**

------

## 8. Syntax Highlighting (Very Important)

CotEditor supports many languages:

-   Shell
-   Python
-   C / C++
-   Java
-   HTML / CSS / JavaScript
-   Markdown
-   JSON / YAML
-   And more

### Set Syntax Manually

-   Menu: **View → Syntax**
-   Choose the language

### Automatic Detection

-   Based on file extension (`.py`, `.sh`, `.json`, etc.)

------

## 9. Find & Replace (Powerful Feature)

### Basic Find

-   `Cmd + F`

### Replace

-   `Cmd + Option + F`

### Advanced Options

-   Case sensitive
-   Whole words
-   **Regular expressions (Regex)**

>   CotEditor’s regex support is excellent for batch edits.

------

## 10. Useful Editing Features

### Multiple Cursors

-   Hold `Option` and click multiple locations

### Column (Vertical) Editing

-   Hold `Option + Shift` and drag

### Line Operations

-   Duplicate line
-   Move line up/down
-   Delete line

(Check **Edit** menu for shortcuts)

------

## 11. Working with Large Files

CotEditor is optimized for:

-   Log files
-   CSV
-   System config files

It opens large files **much faster** than many editors.

------

## 12. Customizing CotEditor

### Preferences

-   `Cmd + ,`

You can customize:

-   Fonts and font size
-   Themes (light / dark)
-   Tab width and indentation
-   Line numbers
-   Wrap lines

### Theme

-   Menu: **Preferences → Appearance**
-   Choose a clean macOS-style theme

## 13. When to Use CotEditor vs Other Editors

| Tool          | Best For                          |
| ------------- | --------------------------------- |
| TextEdit      | Very simple notes                 |
| **CotEditor** | Fast, precise text & code editing |
| VS Code       | Large projects, extensions        |
| Xcode         | Apple development                 |

CotEditor is ideal when you want **speed, simplicity, and control**.

## 14. Recommended Beginner Workflow

1.  Install CotEditor
2.  Set default encoding to **UTF-8**
3.  Enable line numbers
4.  Learn `Cmd + F` and regex
5.  Use it as your **daily text editor**
