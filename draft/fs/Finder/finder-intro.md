# Finder: Intro

## 1. What Is Finder?

**Finder** is the **file manager of macOS**.

You use Finder to:

* Browse files and folders
* Open documents, apps, images, videos
* Copy, move, rename, and delete files
* Connect to disks, USB drives, and network shares
* Search for anything on your Mac

> If you come from Windows: **Finder ≈ File Explorer**
> If you come from Linux: **Finder ≈ file manager (Nautilus, Dolphin, etc.)**

## 2. How to Open Finder

Finder is **always running** on macOS.

### Ways to open a Finder window:

* Click the **Finder icon** (smiling face) in the **Dock**
* Press **Command (⌘) + N** (when Finder is active)
* Click the **Desktop** (Finder becomes active automatically)

You’ll know Finder is active when the **menu bar says “Finder”** at the top.

## 3. Finder Window Layout

A Finder window has **four main areas**:

### ① Toolbar (Top)

Contains:

* Back / Forward buttons
* View options (icons, list, columns, gallery)
* Search bar
* Share, Tags, Action buttons

### ② Sidebar (Left)

Quick access to:

* Favorites (Desktop, Documents, Downloads)
* iCloud Drive
* Locations (disks, USBs, network)
* Tags

You can **customize** it:

```
Finder → Settings → Sidebar
```

### ③ Main Area (Center)

Shows files and folders in the current location.

### ④ Path Bar / Status Bar (Bottom, optional)

Enable them via:

```
View → Show Path Bar
View → Show Status Bar
```

Highly recommended for beginners.

## 4. Important Default Folders

| Folder       | Purpose                              |
| ------------ | ------------------------------------ |
| Desktop      | Files shown directly on your desktop |
| Documents    | Personal documents                   |
| Downloads    | Files downloaded from the internet   |
| Applications | Installed apps                       |
| Pictures     | Photos and images                    |
| Movies       | Videos                               |
| Music        | Audio files                          |

> Tip: **Keep your files organized inside Documents**, not the Desktop.

## 5. Finder Views (Very Important)

Finder offers **four views**. Switch using toolbar icons or shortcuts.

### 1️⃣ Icon View (⌘ + 1)

* Large icons
* Good for images
* Less structured

### 2️⃣ List View (⌘ + 2) ⭐ Recommended

* Shows file details (size, date, kind)
* Expand folders inline
* Best for productivity

### 3️⃣ Column View (⌘ + 3)

* Shows folder hierarchy
* Great for navigating deeply nested folders

### 4️⃣ Gallery View (⌘ + 4)

* Large preview at the top
* Ideal for photos and media

## 6. Basic File Operations

### Select

* Single file: click
* Multiple files: **⌘ + click**
* Range: **Shift + click**
* Select all: **⌘ + A**

### Open

* Double-click
* Or **⌘ + O**

### Rename

* Select file → press **Return**
* Or right-click → Rename

### Move / Copy

* Drag to another folder
* Hold **Option (⌥)** while dragging → Copy

### Delete

* **⌘ + Delete** → Move to Trash
* Empty Trash: right-click Trash → Empty

## 7. Right-Click (Context Menu)

Right-click is extremely important in Finder.

Common actions:

* Open
* Rename
* Move to Trash
* Get Info
* Compress
* Share

> Mac equivalent of Windows “right-click” = **two-finger click on trackpad**

## 8. Search in Finder

Use the **Search Bar (top-right)**.

### Key tips:

* Search results can be limited to:

  * This Mac
  * Current Folder
* Filter by:

  * File type
  * Date
  * Name
  * Size

Click **“+”** on the right to add filters.

## 9. Tags (macOS Feature)

Tags help organize files **without moving them**.

* Right-click file → Tags
* Assign colors or names
* Find tags in Finder sidebar

Example:

* `work`
* `school`
* `important`

## 10. Get Info (Very Useful)

Select a file → **⌘ + I**

Shows:

* File size
* Location
* Permissions
* Default app
* Creation & modification dates

You can:

* Change file name
* Change which app opens the file

## 11. Quick Look (Mac Superpower)

Select a file → press **Space**

Instant preview:

* Images
* PDFs
* Videos
* Text files

No app needed.

## 12. Finder Preferences (Settings)

Open:

```
Finder → Settings
```

Recommended beginner settings:

* ✔ Show hard disks on Desktop
* ✔ Show Path Bar
* ✔ Show Status Bar
* ✔ Enable Tabs

## 13. Finder Tabs (Like a Browser)

* Open new tab: **⌘ + T**
* Close tab: **⌘ + W**
* Switch tabs: **⌘ + Shift + ] / [**

Much cleaner than many windows.

## 14. Useful Finder Shortcuts

| Shortcut      | Action                   |
| ------------- | ------------------------ |
| ⌘ + N         | **N**ew Finder window    |
| ⌘ + T         | New **t**ab              |
| ⌘ + Delete    | Move to Trash            |
| ⌘ + I         | Get **I**nfo             |
| Space         | Quick Look               |
| ⌘ + Shift + . | Show / hide hidden files |
| ⌘ + 1~4       | Switch views             |

## 15. Finder vs Terminal

* Finder = visual, beginner-friendly
* Terminal = text-based, powerful

They work together:

* Right-click folder → **New Terminal at Folder**
* Drag files from Finder into Terminal

## 16. Common Beginner Mistakes

❌ Storing everything on Desktop

❌ Force-quitting Finder unnecessarily

❌ Deleting system files

❌ Ignoring folder structure

✔ Use Documents

✔ Learn List View

✔ Use Search & Tags

## 17. Summary

Finder is:

* The **center of file management** on macOS
* Simple on the surface, powerful underneath
* Best used with **shortcuts + List View + Quick Look**

Once you master Finder, macOS becomes **fast and elegant**.
