## 1. What is Anki?

**Anki** is a flashcard app that helps you **remember things long-term** using a scientifically proven method called **spaced repetition**.

In short:

-   You review cards
-   Anki decides **when** to show them again
-   Easy cards appear less often
-   Hard cards appear more often

This makes studying **efficient and time-saving**.

------

## 2. What is Anki good for?

Anki is especially good for memorization-heavy subjects:

-   Language learning (words, sentences, grammar)
-   Exams (medical, law, CS, IELTS, etc.)
-   Definitions & concepts
-   Code syntax and commands
-   Any “question → answer” knowledge

If you need **long-term memory**, Anki is a great tool.

------

## 3. Core Concepts (Very Important)

Before using Anki, understand these 5 ideas.

### 3.1 Card

A **card** is a single flashcard.

Example:

-   Front:
    `What is TCP?`
-   Back:
    `A connection-oriented transport layer protocol`

You review **cards**, not notes.

------

### 3.2 Note

A **note** is the source of one or more cards.

-   You enter information once (the note)
-   Anki generates cards from it

Example:

| Field    | Content                        |
| -------- | ------------------------------ |
| Question | What is TCP?                   |
| Answer   | A connection-oriented protocol |

A single note can create **multiple cards** (e.g. forward + reverse).

------

### 3.3 Deck

A **deck** is a collection of cards.

Examples:

-   `English`
-   `Operating Systems`
-   `CS408`
-   `Vocabulary::IELTS`

You study **one deck at a time**.

------

### 3.4 Review Buttons

When you review a card, you see buttons like:

-   **Again** → I forgot
-   **Hard** → difficult
-   **Good** → normal
-   **Easy** → very easy

Your choice controls **when Anki shows the card again**.

------

### 3.5 Spaced Repetition

Anki uses an algorithm to schedule reviews:

-   Just learned → review soon
-   Remembered well → review later
-   Forgot → review again quickly

You **do not need to plan reviews manually**.

------

## 5. Creating Your First Deck

1.  Open Anki

2.  Click **Create Deck**

3.  Name it, for example:

    ```
    English Vocabulary
    ```

4.  Select the deck

That’s it.

------

## 6. Adding Your First Card

1.  Click **Add**
2.  Choose a **Note Type**
    -   Start with **Basic**
3.  Fill in:
    -   Front: `What does "efficient" mean?`
    -   Back: `Doing something with little wasted time or effort`
4.  Click **Add**

You just created your first card 🎉

------

## 7. Studying Cards

1.  Select a deck
2.  Click **Study Now**
3.  Read the front
4.  Think of the answer
5.  Press **Show Answer**
6.  Choose a button:
    -   Forgot? → **Again**
    -   Remembered? → **Good**

**Be honest**. Anki only works if your answers are truthful.

------

## 8. How Much Should You Study Per Day?

For beginners:

-   **10–30 new cards per day**
-   Review everything Anki schedules

Consistency is more important than quantity.

>   15 minutes every day beats 3 hours once a week.

------

## 9. Writing Good Cards (Very Important)

Bad cards make Anki painful.
Good cards make Anki powerful.

### 9.1 One Fact per Card

❌ Bad:

```
Explain TCP and UDP and their differences
```

✅ Good:

```
What is TCP?
What is UDP?
```

------

### 9.2 Keep Answers Short

❌ Bad:

```
Explain the OSI model in detail
```

✅ Good:

```
How many layers does the OSI model have?
```

------

### 9.3 Use Your Own Words

Cards you understand are remembered better than copied text.

------

## 11. Syncing Across Devices

1.  Create a free account at **AnkiWeb**
2.  In Anki:
    -   Click **Sync**
    -   Log in
3.  Sync on all devices

Your cards and progress stay consistent.

------

## 12. Common Beginner Mistakes

Avoid these:

-   Adding too many new cards per day
-   Making very long cards
-   Skipping reviews
-   Memorizing without understanding
-   Studying only before exams

Anki is for **daily, long-term use**.

------

## 13. Recommended Beginner Workflow

A simple daily routine:

1.  Open Anki
2.  Review all due cards
3.  Add a few new cards
4.  Close Anki

Time needed: **10–30 minutes**

------

## 14. When to Customize More

At first:

-   Use default settings
-   Use Basic note type

Later (optional):

-   Custom note types
-   Cloze deletion
-   Tags
-   Add-ons

Don’t rush this.

------

## 15. Final Advice

-   Anki is a **tool**, not magic
-   Understanding comes first, memorization second
-   Small daily progress compounds over time

If used correctly, Anki can become one of the most powerful study tools you’ll ever use.
